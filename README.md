# MRPL AI Workstation 🛢️⚡

An Enterprise AI Operating System prototype developed for the Smart India Hackathon (SIH) 2026. This workstation is designed to process and manage real Mangalore Refinery and Petrochemicals Limited (MRPL) data, including SOPs, emissions reports, and valve maintenance telemetry, all within a secure, high-performance dark-mode interface.

## 🚀 Tech Stack
* **Frontend:** React, Tailwind CSS, shadcn/ui
* **Package Manager & Runtime:** Bun
* **Version Control:** Git & GitHub

## 📋 Prerequisites
Before you begin, ensure you have the following installed on your local machine:
1. **Git:** [Download & Install Git](https://git-scm.com/)
2. **Bun:** An ultra-fast JavaScript runtime and package manager.
   * *Windows Installation (Run in a fresh PowerShell as Administrator):*
     ```powershell
     powershell -c "irm bun.sh/install.ps1 | iex"
     ```
   * *Note: Restart your terminal after installing Bun.*
